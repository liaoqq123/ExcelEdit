# 奶龙检索大师（ExcelEdit）

奶龙检索大师是一款 Windows 桌面检索工具，用于在指定文件夹及其子文件夹中查找 Excel 工作簿、工作表、单元格和普通文件。它将检索结果按层级展示，并支持直接打开文件、定位工作表或选中命中的单元格。

## 快速开始

1. 启动 `dist\奶龙检索大师.exe`，或按下方“源码运行”方式启动程序。
2. 在顶部输入或选择“文件夹地址”。地址框会记住最近使用过的目录。
3. 输入检索内容；文件检索可以留空以显示指定范围内的全部文件。
4. 选择检索模式：工作表检索、单元格检索或文件检索。
5. 如需限制检索范围，点击顶部的“检索设置”，设置条件后点击“保存”。
6. 点击“检索”。检索过程中可以点击“取消”。

## 检索模式

| 模式 | 检索内容 | 结果展示与操作 |
| --- | --- | --- |
| 工作表检索 | Excel 工作簿名称、文件路径和工作表名称 | 表格视图；双击可打开工作簿并切换到对应工作表。 |
| 单元格检索 | Excel 单元格中已保存的显示内容 | “工作簿 → 工作表 → 单元格”三级目录；单元格使用 `A21`、`AB7` 这类 Excel 地址，双击可打开并选中该单元格。 |
| 文件检索 | 文件名、文件地址，以及可选的文件夹名称 | 可切换缩略图和表格视图；结果按所在文件夹分组，不分页。 |

### 工作表检索

- 工作簿和工作表按归属关系展开显示。
- 每个工作表都可使用“查找引用”，查询类似 `FOREIGN:XXX.Id` 的引用目标。
- “启用”状态默认由工作表名称判断：名称以 `$` 开头的工作表视为未启用。

### 单元格检索

- 左侧目录列展示工作簿、工作表和单元格地址；右侧展示命中的数据内容。
- 工作簿行提供“打开目录”按钮，可在资源管理器中定位源文件。
- `.xlsx`、`.xlsm`、`.xltx`、`.xltm` 会先进行快速预筛，再定位命中单元格。
- 公式检索的是 Excel 已保存的计算结果，不检索公式文本本身。
- 日期、百分比和常见数字格式按 Excel 显示值参与匹配。
- 单个损坏或无法读取的文件会被跳过，不会中断其余文件的检索。

### 文件检索

- 缩略图视图会直接预览 `.png`、`.jpg`、`.jpeg`、`.gif`、`.bmp`、`.webp` 图片；其他类型使用文件类型图标。
- 文件卡片可以打开所在目录；文件夹卡片可以直接打开该文件夹。
- 表格视图与缩略图视图可以随时切换。
- 单元格检索和文件检索最多显示 20,000 条结果，避免结果过多影响界面响应。

## 检索设置

点击顶部“检索设置”打开统一的设置窗口。所有条件会按以下分类列在同一个窗口中：

- 通用设置：精确查找。
- 工作表检索设置：仅检索启用表格；该条件同样作用于单元格检索。
- 单元格检索设置：仅检索启用数据。
- 文件检索设置：检索文件夹、仅检索指定后缀文件、文件后缀列表。

检索设置会保存到本地，下次启动时自动恢复。

## 软件设置

点击顶部“设置”可打开软件设置窗口。

### 引用数据修改

用于配置“查找引用”的识别规则，包括：

- 引用样例
- 引用行
- 引用表格名称
- 引用字段
- 引用字段行

默认规则按第 6 行识别类似 `FOREIGN:BBB.Id` 的内容。

### 基础配置与未启用标识

- 表头长度：单元格检索时跳过指定的表头行数。
- 屏蔽空白表头：跳过表头为空的列。
- 列禁用、行禁用、行区间：按配置的标识或区间过滤未启用数据。
- 表格未启用标识：默认是 `$`。

### 关于与软件背景图

- 可以设置“使用说明”按钮打开的网址。
- 可以通过“软件背景图 → 选择图片”打开 Windows 文件选择窗口，选择常见图片格式。
- 点击“保存修改”后，图片会转存到 `%LOCALAPPDATA%\NailongSearchMaster\software_background.png`。原始图片随后被移动或删除，不影响软件背景。
- 顶部工具条、地址输入条和检索操作条会以 85% 不透明的浅色效果叠加在背景图上，保证背景可见且文字清晰。
- 点击“清除”并保存，可恢复默认背景。

## 支持的 Excel 文件

- `.xlsx`
- `.xlsm`
- `.xltx`
- `.xltm`
- `.xls`
- `.xlsb`

Excel 的临时文件会自动跳过，例如以 `~$` 开头的文件。

## 本地数据与缓存

程序会保存最近使用的文件夹、输入内容、检索设置、软件设置、帮助链接和背景图路径。

- 配置缓存：`%LOCALAPPDATA%\NailongSearchMaster\cache_data.json`
- 背景图片副本：`%LOCALAPPDATA%\NailongSearchMaster\software_background.png`
- 文件夹历史最多保存 20 条。
- 工作表列表会根据文件大小和修改时间缓存；Excel 文件发生变化后会自动重新读取。
- 旧版本程序目录中的 `cache_data.json` 会在首次启动时迁移读取。

## 源码运行

需要 Python 3.10 或更高版本。建议使用虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 注意事项

- 直接定位工作表或单元格需要 Windows 与 Microsoft Excel。
- 程序只能读取磁盘上已保存的 Excel 内容；正在编辑但未保存的修改不会被检索。
- 取消检索采用安全取消：会在当前文件或当前 XML 解析步骤完成后尽快停止，不会强制终止线程。
