# ExcelEdit

ExcelEdit 是一个用于批量检索本地 Excel 文件的桌面工具。它可以扫描指定文件夹中的 Excel 工作簿，查看工作簿与工作表关系，搜索单元格内容，并支持双击直接打开对应工作簿、工作表或单元格。

## 主要功能

### 工作表检索

- 选择一个文件夹后，检索该文件夹及子文件夹中的 Excel 文件。
- 展示工作簿名称、工作表名称和工作表启用状态。
- 支持按输入内容筛选工作簿名、路径或工作表名。
- 工作簿和工作表按归属关系展示。
- 双击结果可打开对应工作簿并切换到指定工作表。
- 检索过程中可点击红色“取消”按钮停止当前检索。

### 单元格检索

- 在选定文件夹内搜索所有 Excel 单元格内容。
- 结果展示匹配数据所在的工作簿、工作表、行、列和单元格内容。
- 双击匹配结果可打开对应工作簿、切换到指定工作表，并选中对应单元格。
- `.xlsx/.xlsm/.xltx/.xltm` 使用 XML 方式检索，先命中关键词再定位单元格位置。
- 公式单元格检索的是 Excel 已保存的缓存结果，不检索公式文本本身。
- 检索过程中可点击红色“取消”按钮停止当前检索。

### 引用表查找

- 工作表检索结果中，每个工作表后方提供“查找引用”按钮。
- 默认按第 6 行查找类似 `FOREIGN:XXX.Id` 的引用结构。
- `XXX` 会被识别为引用表名称，并在当前工作表下方展示引用结果。
- 引用识别规则可在“设置”中调整，包括引用样例、引用行、引用表格名称、引用字段和字段行。

### 启用状态与过滤

- 工作表启用状态由工作表名称判断。
- 默认未启用标识为 `$`：工作表名称以 `$` 开头时视为“未启用”，否则视为“启用”。
- 可勾选“仅检索启用表格”，跳过未启用工作表。
- 可勾选“仅检索启用数据”，结合设置中的行列规则过滤未启用数据。
- 设置中支持：
  - 表头长度过滤。
  - 列未启用标识过滤。
  - 行禁用标识过滤。
  - 行区间过滤。

### 缓存数据

- 程序会自动记录上次选择的文件夹、输入内容、设置项和帮助链接。
- 工作表名称检索会缓存工作簿的工作表列表，并通过文件大小和修改时间判断缓存是否仍可使用。
- Excel 文件发生变化后，对应缓存会自动失效并重新读取。
- 缓存文件为程序目录下的 `cache_data.json`。

## 支持的 Excel 类型

- `.xlsx`
- `.xlsm`
- `.xltx`
- `.xltm`
- `.xls`
- `.xlsb`

临时文件会被自动跳过，例如以 `~$` 开头的 Excel 文件。

## 使用方法

1. 启动程序。
2. 点击“选择文件夹”，选择需要检索的 Excel 文件夹。
3. 在“输入内容”中填写筛选或搜索关键词。
4. 在下拉框中选择检索模式：
   - `工作表检索`
   - `单元格检索`
5. 点击“检索”开始。
6. 检索中如需停止，点击红色“取消”按钮。
7. 双击结果打开对应工作簿、工作表或单元格。

## 设置说明

点击顶部“设置”按钮可打开设置窗口。

### 引用数据修改

用于配置“查找引用”的识别规则。

- 引用样例：默认 `FOREIGN:BBB.Id`
- 引用行：默认第 `6` 行
- 引用表格名称：样例中代表表名的部分，默认 `BBB`
- 引用字段：样例中代表字段名的部分，默认 `Id`
- 引用字段行：用于读取字段名称的行，默认第 `1` 行

### 基础配置

- 启用表头长度后，单元格检索会跳过指定数量的表头行。

### 未启用标识

- 表格未启用标识：默认 `$`。
- 列禁用：按指定行中的标识判断列是否启用。
- 行禁用：按指定列中的包含文本判断行是否禁用。
- 行区间：按指定列中的起始数据和终止数据判断可检索区间。

### 关于

- 可配置“使用说明”按钮打开的链接。

## 运行方式

如果使用已打包程序，直接运行：

```powershell
dist\ExcelEdit.exe
```

如果使用源码运行，需要 Python 3.10 或更高版本，并安装依赖：

```powershell
pip install customtkinter openpyxl xlsxwriter xlrd pyxlsb
python main.py
```

## 注意事项

- 双击打开指定工作表或单元格依赖 Windows 环境中的 Microsoft Excel。
- 如果 Excel 文件正在编辑但尚未保存，程序只能读取磁盘上已保存的内容。
- 公式结果必须是 Excel 保存过的缓存值；如果文件没有被 Excel 保存过，公式结果可能为空或不是最新结果。
- 取消检索是安全取消：程序会在当前文件或当前 XML 解析步骤结束后尽快停止，不会强制终止线程。
