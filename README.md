# 奶龙检索大师（ExcelEdit）

奶龙检索大师是一款 Windows 桌面检索工具，用于在指定文件夹及其子文件夹中查找 Excel 工作簿、工作表、单元格和普通文件。它将检索结果按层级展示，并支持直接打开文件、定位工作表或选中命中的单元格。

当前界面采用柔和灰蓝配色，提供可见筛选标签、目录固定、结果内筛选、只读预览和 XLSX 导出。检索和预览读取在后台执行，工具不会修改被检索的源文件。

## 快速开始

1. 启动 `dist\奶龙检索大师.exe`，或按下方“源码运行”方式启动程序。
2. 在顶部输入或选择“工作目录”。地址框会记住最近使用过的目录，可将常用目录固定到历史列表顶部。
3. 选择检索模式：工作表、单元格、文件或 JSON 检查。
4. 工作表、单元格和文件检索需要输入关键词；JSON 检查可以留空。
5. 如需限制检索范围，点击“＋ 更多条件”设置条件后保存；当前条件以标签显示，点击标签可切换或移除。
6. 点击“检索”或按 Enter。检索过程中可取消，并保留已经找到的部分结果。

## 结果操作与预览

- 单击具体单元格结果，在右侧只读预览命中内容和附近最多 5×5 个单元格；关键词以浅黄色标记。周边表格支持横向滚动，图片结果显示大图、尺寸、大小和修改时间。预览按需在后台读取，不参与文件夹检索。
- 超长内容的预览最多显示 100,000 个字符；复制命中内容仍使用原文，不受预览截断影响。
- “预览”按钮可收起右侧面板；“舒适 / 紧凑”调整结果行高。
- 文件操作统一在结果底部：主按钮根据选择显示“打开 Excel / 在 Excel 中定位 / 打开文件 / 进入文件夹”，旁边为“打开所在目录”和“复制内容”。右侧预览区只展示信息和复制路径，不再重复放打开按钮。
- 双击结果或按 Enter 与底部主按钮执行同一操作；分组使用左侧箭头或“全部展开 / 全部收起”控制。没有选择时打开按钮不可用，相同目标打开过程中按钮显示进度并阻止重复点击。
- 右键菜单可复制内容、单元格地址或文件路径，打开文件或目录；工作表和单元格结果还可选择“只看此工作表”。复制单元格内容会保留原始换行。
- “打开所在目录”按完整路径在实际父目录中选中文件或子文件夹；双击文件夹则进入它，磁盘或共享根目录直接打开根目录。
- 打开 Excel 或文件夹时，由系统处理正常显示和激活；后台任务完成后只核对状态，不再恢复窗口或重复激活。Excel 已被最小化或切换到后台时跳过剩余自动定位，不会等待重新切回后再操作。底部状态分别反馈打开、定位和窗口状态。
- 在已有结果中继续筛选不会重新扫描磁盘；清除筛选后可以恢复全部已检索结果。
- “导出”将当前筛选结果保存为 XLSX，原始内容按文本写入，不执行公式；收起分组不影响导出的结果。
- 导出失败时保留目标位置原有的文件；单元格内容超过 Excel 的 32,767 字符上限时明确报错，不静默截断。
- 固定目录、显示密度、预览开关和文件视图会自动保存。
- 切换顶部检索模式不会自动发起检索，当前结果仍可操作；点击“检索”后才会显示新结果。

### 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Enter | 在关键词框开始检索；在结果列表执行底部主按钮对应的打开或定位操作。 |
| Ctrl+C | 在结果表格复制选中内容；在文件缩略图视图复制选中文件的完整路径。 |
| Ctrl+F | 聚焦“在结果中查找”输入框。 |
| Ctrl+L | 聚焦工作目录输入框。 |
| Esc | 清除结果内筛选和“只看此工作表”范围。 |
| 方向键、Home、End | 在文件缩略图视图选择结果；Enter 或空格打开所选项。 |

## 检索模式

| 模式 | 检索内容 | 结果展示与操作 |
| --- | --- | --- |
| 工作表检索 | Excel 工作簿名称、文件路径和工作表名称 | 表格视图；双击可打开工作簿并切换到对应工作表。 |
| 单元格检索 | Excel 单元格中已保存的显示内容 | “工作簿 → 工作表 → 单元格”三级目录；单元格使用 `A21`、`AB7` 这类 Excel 地址，双击可打开并选中该单元格。 |
| 文件检索 | 文件名、文件地址，以及可选的文件夹名称 | 可切换缩略图和表格视图；结果按所在文件夹分组，不分页。 |
| JSON 格式检查 | 非 `$` 工作表中由第 4、6 行识别出的 JSON 数据列 | 表格显示每处格式错误的位置、原文和原因；双击可打开并定位到错误单元格。 |

工作表检索和单元格检索固定只处理 `.xlsx`、`.xlsm`、`.xltx`、`.xltm`、`.xls`、`.xlsb`，界面显示“仅 Excel 文件”。遍历时先按文件名过滤，其他文件不进行文件类型检查或内容读取；子目录继续递归查找 Excel，`~$` 临时锁文件自动跳过。

### 工作表检索

- 每个匹配的工作表独立成行，显示所属工作簿、启用状态和操作入口。
- 每个工作表都可使用“查找引用”，查询类似 `FOREIGN:XXX.Id` 的引用目标。
- “启用”状态默认由工作表名称判断：名称以 `$` 开头的工作表视为未启用。

### 单元格检索

- 左侧目录列展示工作簿、工作表和单元格地址；右侧展示命中的数据内容。
- 选中工作簿、工作表或单元格后，底部“打开所在目录”可在资源管理器中定位源文件；“在 Excel 中定位”打开对应工作表或单元格。
- `.xlsx`、`.xlsm`、`.xltx`、`.xltm` 会先进行快速预筛，再定位命中单元格。
- 公式检索的是 Excel 已保存的计算结果，不检索公式文本本身。
- 日期、百分比和常见数字格式按 Excel 显示值参与匹配。
- 支持显示值的部分匹配，例如搜索 `2026` 可命中 `2026-07-14`，搜索 `tru` 可命中布尔值 `TRUE`。
- XML 数字转义、富文本和 Unicode 大小写按解码后的文本匹配，避免快速预筛漏掉结果。
- 单个损坏或无法读取的文件会被跳过，不会中断其余文件的检索。

### 文件检索

- 缩略图视图会直接预览 `.png`、`.jpg`、`.jpeg`、`.gif`、`.bmp`、`.webp` 图片；其他类型使用文件类型图标。
- 单击文件卡片查看预览，双击或按 Enter 打开文件；底部操作栏及右键菜单提供“打开所在目录”。文件夹的主操作为“进入文件夹”，目录定位则在父目录选中它。
- 表格视图与缩略图视图可以随时切换。
- 缩略图只绘制当前可见区域及少量缓冲卡片，图片在后台读取，结果仍按文件夹分组连续滚动，不分页。
- 表格结果分批显示；工作表操作按钮只为可见行创建，滚动时复用。

### JSON 格式检查

- 不需要填写“输入内容”；选择该模式后点击“检索”即可开始检查。
- 自动跳过工作表名称以 `$` 开头的表格。
- 仅当同一列的第 4 行和第 6 行单元格都能正确解析为 JSON 时，该列才会被识别为 JSON 数据列。
- 从第 4 行起检查该列的所有非空单元格；空白单元格不会报错。
- 结果表格列出工作簿、工作表、Excel 单元格地址、JSON 内容和具体错误原因，最多显示 20,000 处错误。
- 达到错误上限会停止检查，界面会明确提示结果可能不完整。

### 检索进度与失败明细

- 检索过程中显示已扫描数量、当前文件、已找到的结果数量和耗时。
- 正常完成、用户取消和达到结果上限分别提示，不将提前停止的检索描述为完整扫描。
- 取消后保留已找到的部分结果；再次检索会清空旧结果。
- 单元格检索、文件检索和 JSON 检查分别最多收集 20,000 条命中或错误；达到上限会提前停止，并提示结果可能不完整。
- 如果遇到无法读取的文件或目录，点击底部的“失败明细”查看路径和底层错误原因；其他文件继续检索。

## 检索设置

点击“＋ 更多条件”打开统一的检索设置窗口。所有条件会按以下分类列在同一个窗口中：

- 通用设置：精确查找。
- 工作表检索设置：仅检索启用表格；该条件同样作用于单元格检索。
- 单元格检索设置：仅检索启用数据。
- 文件检索设置：检索文件夹、仅检索指定后缀文件、文件后缀列表。

检索设置会保存到本地，下次启动时自动恢复。

更改筛选标签或“更多条件”中的选项后，需要重新检索才能应用新条件。“重置”清除检索选项；表头长度、空白表头列等基础规则仍由软件设置控制。未勾选“仅检索启用数据”时，已开启的表头跳过和空白表头列规则仍然有效。

## 软件设置

点击顶部“设置”可打开软件设置窗口。

### 引用数据修改

用于配置“查找引用”的识别规则，包括：

- 引用样例
- 引用行
- 引用表格名称
- 引用字段
- 引用字段行

默认规则按第 6 行识别类似 `FOREIGN:BBB.Id` 的内容。

### 基础配置与未启用标识

- 表头长度：单元格检索时跳过指定的表头行数。
- 屏蔽空白表头：跳过表头为空的列。
- 列禁用、行禁用、行区间：按配置的标识或区间过滤未启用数据。
- 表格未启用标识：默认是 `$`。

### 关于与软件背景图

- 可以设置“使用说明”按钮打开的网址。
- 可以通过“软件背景图 → 选择图片”打开 Windows 文件选择窗口，选择常见图片格式。
- 点击“保存修改”后，图片会转存到 `%LOCALAPPDATA%\NailongSearchMaster\software_background.png`。原始图片随后被移动或删除，不影响软件背景。
- 顶部工具条、地址输入条和检索操作条会以 85% 不透明的浅色效果叠加在背景图上，保证背景可见且文字清晰。
- 点击“清除”并保存，可恢复默认背景。

## 支持的 Excel 文件

- `.xlsx`
- `.xlsm`
- `.xltx`
- `.xltm`
- `.xls`
- `.xlsb`

Excel 的临时文件会自动跳过，例如以 `~$` 开头的文件。

## 本地数据与缓存

程序会保存最近使用的文件夹、输入内容、检索设置、软件设置、帮助链接和背景图路径。

- 配置缓存：`%LOCALAPPDATA%\NailongSearchMaster\cache_data.json`
- 背景图片副本：`%LOCALAPPDATA%\NailongSearchMaster\software_background.png`
- 文件夹历史最多保存 20 条；最多固定 10 个目录，固定项显示在历史列表顶部。
- 显示密度、右侧预览开关、文件缩略图 / 表格视图会一并保存；结果内筛选和检索结果不持久化。
- 工作表列表会根据文件大小和修改时间缓存；Excel 文件发生变化后会自动重新读取。
- 旧版本程序目录中的 `cache_data.json` 会在首次启动时迁移读取。

## 源码运行

需要 Python 3.10 或更高版本。建议使用虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

### 不创建窗口的检查

在项目根目录安装开发依赖，再使用统一的无窗口检查入口：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe scripts\check_headless.py
.\.venv\Scripts\python.exe benchmarks\benchmark_performance.py
```

`check_headless.py` 只加载明确列出的无窗口测试，并阻止意外创建 Tk 窗口、调用原生窗口接口或打开外部程序。添加 `-v` 查看每项检查，添加 `--list` 查看检查范围。

测试和性能脚本使用隔离配置或临时文件，不读写用户检索历史和设置。图片生命周期和刷新调度测试通过假对象验证切换、清空、关闭及重复刷新。打开操作测试模拟系统调用；定位脚本测试在隐藏 PowerShell 中使用假工作簿，不调用真实 Excel 或 COM。性能脚本默认检查共享字符串预筛、50,000 单元格工作簿检索，以及中文、公式和数据过滤场景下的未命中预筛。`xlsxwriter` 仅用于生成测试和性能样本，归入开发依赖；程序导出使用 `openpyxl`。

### 完整界面检查

完整回归包含会显示窗口的界面测试，仅在允许弹出测试窗口时手动执行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

性能脚本添加 `--gui` 才会创建界面并测量 500 / 20,000 条文件结果的首屏和滚动耗时。比较检索速度时，应固定目录、关键词和筛选设置，并区分文件扫描、结果显示与预览读取三个阶段。

### 打包 EXE

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm ExcelEdit.spec
```

输出文件为 `dist\奶龙检索大师.exe`。更新源码或 EXE 后需退出旧进程再启动；在 PyCharm 中运行源码时，先停止当前运行，再重新执行 `main.py`。

## 代码结构

| 模块 | 职责 |
| --- | --- |
| `main.py`、`gui.py`、`main_layout.py`、`popup_gui.py` | 启动、界面交互、主布局和设置窗口。 |
| `app_preferences.py`、`input_validation.py` | 配置默认值、旧字段兼容、历史目录整理和输入校验，不依赖界面控件。 |
| `cache_store.py` | 配置文件路径、旧缓存迁移和原子读写。 |
| `excel_common.py`、`cell_search.py`、`worksheet_search.py` | Excel 文件枚举、读取和检索。 |
| `file_search.py`、`json_validation.py` | 普通文件检索和 Excel JSON 数据检查。 |
| `desktop_open.py`、`windows_shell.py`、`window_activation.py` | 打开与定位、系统外壳调用和只读窗口状态查询。 |
| `result_preview.py`、`file_result_view.py`、`result_export.py` | 结果预览、文件视图和 XLSX 导出。 |
| `scripts/check_headless.py`、`tests/`、`benchmarks/` | 无窗口检查、回归测试和性能对比。 |

后续较大的结构调整可以优先将单元格检索与 JSON 检查共用的 OpenXML 读取逻辑整理为独立模块，减少跨模块引用私有函数；这类调整应结合显示值匹配和快速预筛的现有检查逐步完成。

## 最近修复

- 拆分界面中的配置处理与输入校验，保留旧配置兼容；清理未使用的接口、重复包装和主动激活窗口代码。
- 统一无窗口检查入口，将测试专用依赖与运行依赖分开。
- JSON 检查结果支持按 Excel 单元格地址进行结果内筛选。
- 修复快速预筛对中文和 XML 转义判断过宽时触发大量完整解析的问题，保留显示值匹配能力。
- 修复图片预览切换、清空和关闭时的图片引用释放顺序，避免出现 `image "pyimage3" doesn't exist` 一类错误。
- 关闭窗口时先取消任务和定时回调，再销毁控件；不再为清空预览而重新刷新界面。
- 避免子控件变化重复触发整个窗口的背景刷新，并跳过尺寸未变化时的背景和遮罩重绘。
- 整目录 Excel 检索先按文件名和后缀排除非 Excel 与临时锁文件，再检查文件状态，减少大型工程目录中的重复磁盘查询；搜索范围和过滤规则保持一致。
- 修复子文件夹“打开所在目录”直接进入文件夹的问题，改为 Windows 原生项目定位；路径中的中文、空格、逗号按原样传递。
- Excel 文件先通过系统正常打开，与在资源管理器中双击文件一致；普通打开不依赖自动化助手。工作表和单元格定位在打开之后执行，连接失败或超时会明确提示，不阻断文件打开，也不重复打开文件。
- 自动定位仅连接已经打开且可见的目标工作簿，不创建 Excel 自动化实例、不更改整个应用的可见性，避免带出空窗口或其他隐藏窗口。

Windows 前台激活受系统规则限制，程序会检查实际激活结果，无法切到前台时显示对应状态。相关接口说明：[Windows 项目定位](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shopenfolderandselectitems)、[前台窗口激活](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow)。

## 注意事项

- 直接定位工作表或单元格需要 Windows 与 Microsoft Excel。
- 程序只能读取磁盘上已保存的 Excel 内容；正在编辑但未保存的修改不会被检索。
- 取消检索采用安全取消：会在当前文件或当前 XML 解析步骤完成后尽快停止，不会强制终止线程。
